# Curated sample results

This directory contains text-only examples useful for understanding expected and
observed diagnostic behavior. It deliberately contains no private Pokémon saves
and no commercial ROM data.

- `nintendo-mbc3.md` — Nintendo-documented expected RTC/SRAM behavior; the recorded
SameBoy reference runs matched it.
- `everdrive-x7-observed.md` — previously observed alias signatures on the tested X7.

Raw future diagnostic captures can be attached to issue/forum discussions when
needed, but the repository itself does not need the user's historical save files.
